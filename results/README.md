# Results Directory

This directory contains the verified catalogs, simulation outputs, ablation data, and evolution artifacts used by the paper.

## Catalogs

| File | Contents | Notes |
|------|----------|-------|
| `weight5_publication_catalogue.jsonl` | 1,142 retained weight-five presentations in 630 colored-BLISS classes | Normalized, self-contained publication snapshot with per-presentation and class-level distance evidence, provenance, connectivity, decompositions, and source hashes. Generated by `scripts/build_weight5_publication_catalogue.py`; every retained row has exact evidence or a certified positive lower bound. |
| `weight5_publication_manifest.json` | Hash manifest and accounting for the normalized weight-five catalogue | Pins all raw, verification, attribution, component-certificate, low-weight-audit, and normalization inputs. The retained catalogue has 398 exact and 744 nonexact presentations (64 with rigorous upper evidence and 680 with decoder estimates), forming 227 exact and 403 nonexact classes (53 with rigorous upper evidence and 350 with decoder estimates). |
| `weight5_component_certifications.jsonl` | Seven exact connected-component distance certificates and three explicit BB matches | The `d=2` parent is excluded from the publication catalogue; six exact `d>=3` parents remain. |
| `weight5_css_low_weight_audit.jsonl` | Deterministic weight-≤4 audit of all 858 formerly direct-U CSS presentations | Audits 492 colored-Tanner class representatives using syndrome/row-space-quotient hashing; finds 64 exact low-weight classes and excludes weights 1–4 in 428 classes. Generated by `scripts/audit_weight5_css_low_weight.py`. |
| `weight5_css_upper_bound_witnesses.jsonl` | Explicit witnesses tightening ten CSS upper endpoints | Records and independently verifies X- and Z-sector logical operators for nine decoder-scalar corrections and one MILP-incumbent refinement; generated by `scripts/audit_weight5_css_upper_bound_witnesses.py`. |
| `weight5_component_classes.jsonl` | 608 component-level colored-BLISS classes from 630 parent classes | Replaces every homogeneous replicated parent by one connected component before canonicalization; generated by `scripts/audit_weight5_component_classes.py`. |
| `weight5_challenge_connectivity_audit.jsonl` | Invariant row-space audit of all 102 records in the pinned QEC Challenge comparison snapshots | Validates submitted CSS matrices, dimensions, commutation, check weights, logical witnesses, component dimensions, and homogeneous-component isomorphism; generated from upstream commit `3b50503b058a` by `scripts/audit_qldpc_challenge_connectivity.py`. |
| `weight5_pbb_component_certifications.jsonl` | Four explicit connected PBB component matches | Transfers exact all-logical MILP distances from homogeneous, pairwise-isomorphic disconnected parents only after a positive colored-BLISS match; generated by `scripts/certify_weight5_pbb_components.py`. |
| `weight5_pbb_component_lc_audit.jsonl` | Complete LC-to-CSS audit of the four PBB `[[12,2,3]]` component classes | Exhausts all per-qubit Clifford assignments with a rank-pruned, generator-basis-invariant search; all four classes are certified not LC-equivalent to CSS. Generated by `scripts/audit_weight5_pbb_component_lc.py`. |
| `weight5_lin_pryadko_audit.json` | Ten reconstructed weight-five 2BGA representatives | Pins the Lin--Pryadko archive revision and GAP decoding; records seven exact all-logical MILP certificates and three time-limited upper-bound audits; proves presentation equivalence for `[[96,4,10]]`; generated by `scripts/audit_lin_pryadko_weight5.py`. |
| `weight5_quotient_character_analysis.json` | Reproducible algebraic-stratum audit of the retained catalogue | Records C3/C5/C7/C15 quotient coverage by lattice, exact cyclic-gcd multiplicities, the common-kernel versus `k_S` comparison, and the descriptive 28-class versus 86-class noncyclic control; generated by `scripts/analyze_weight5_quotient_characters.py`. |
| `weight5_css_weight5_witnesses.jsonl` | Explicit weight-five logical witnesses for 45 exact CSS presentations | Contains validated X- and Z-sector logicals (90 total), with direct weight, syndrome, and stabilizer-row-space checks; generated by `scripts/audit_weight5_css_weight5_witnesses.py`. |
| `weight5_referee_v4_checks.json` | Focused verification requested in referee report v4 | Audits absent PBB lattices, CSS sector agreement, MILP provenance/retention, and explicit optimal five- versus six-layer interaction schedules; generated by `scripts/audit_weight5_referee_v4.py`. |
| `weight5_uniform_baseline/` | Three-replicate logged-output-matched uniform CSS transfer control | Contains every sampled draw, distance record, deterministic weight-four audit, per-lattice summary, aggregate comparison, and hash manifest for 6,444 distance evaluations per seed. The primary comparison is complete with zero active errors; the separately defined all-logical MILP follow-up is unperformed. For candidates surviving the weight-four audit, exact control results are transferred only across matching exact catalogue-class digests. A repair ledger preserves the 631 one-variable constructor incompatibilities, 16 balanced selection swaps, all superseded records, and intermediate hashes. Generated by `scripts/run_weight5_uniform_baseline.py`. |
| `ilp_catalog.json` | 97 BLISS-distinct CSS BB codes | MILP distances; exact where solver optimality was certified, otherwise incumbent upper bounds. |
| `campaign7_publication_merged.jsonl` | 368 BLISS-distinct non-CSS PBB codes | Canonical PBB catalog. `d` is the publication distance value; `d_is_exact`/`trust_level` distinguish exact distances from trusted or partial upper bounds. Deep MILP evidence is retained as `d_deep_milp` where available. |
| `campaign7_deep_milp.jsonl` | Deep MILP pass over 149 PBB catalog entries | Includes per-logical incumbent/optimality details and downward corrections. |
| `campaign7_dedup.jsonl` | BLISS-deduplicated PBB candidates before publication re-verification | Useful for reproducing the Campaign 5 verification pipeline. |

The completed uniform control records 287,489 rank draws, 19,332 distance
evaluations, and 17,748 low-weight audits across three seeds.  The authoritative
`weight5_uniform_baseline/summary.json` reports the per-seed statistics, pooled
coverage totals, exact catalogue-class overlaps, unresolved exact-follow-up
classes, protocol validation, and repair-ledger validation.
The SHA-256 digest of the untracked wrapper source loaded by the initial
selection/distance run is recorded, but those exact wrapper bytes were not
separately archived.  The released current script implements the deterministic
replay and repair; the raw records, configuration hashes, intermediate repair
hashes, and final manifest are the authoritative execution provenance.

Current PBB accounting from `campaign7_publication_merged.jsonl`: 368 rows, 251 EXACT, 110 TRUSTED, 7 PARTIAL.
